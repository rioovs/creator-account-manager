Creator Account Manager

Creator Account Manager is a private web dashboard used by its owner to manage their own TikTok accounts in one place: publishing videos, and viewing account and video performance.

The app connects to TikTok only through the official TikTok for Developers APIs (Login Kit, Content Posting API and the user/video data scopes), after each account owner explicitly authorizes it.
